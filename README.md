# tripleten-sprint-7
Proyecto de aplicaciones web - TripleTen Data Scientist

Análisis de vehiculos usados

Aplicación web interactiva desarrollada con Python, Pandas, Plotly y Streamlit, que permite explorar un conjunto de datos de anuncios de vehículos usados.

Funcionalidades

- Visualización inicial de los datos.
- Histograma interactivo para analizar la distribución de precios.
- Gráfico de dispersión para explorar la relación entre kilometraje y precio.
- Selección  de visualizaciones mediante botones interactivos.

Tecnologías utilizadas

- Python
- Pandas
- Plotly Express
- Streamlit

Instalación y ejecución local

1. Clonar un repositorio:
git clone https://github.com/jarch777/tripleten-sprint-7.git

2. Instalar las dependencias:
pip install -r requirements.txt

3. Ejecutar la aplicación:

streamlit run app.py
